2. 用户提醒器

2.1. 获取当前用户具有查询权限的就诊提醒记录

URL: https://dev.gateway.api.asialjim.cn/api/rest/clinc/prescription/reminder/list

Type: GET

Author: Asial Jim

Content-Type: application/x-www-form-urlencoded

Description: 当用户是手机号用户时，只能查询自己的提醒记录，当用户时专业用户时可以查询所有记录或者根据姓名、证件号、手机号查询记录
